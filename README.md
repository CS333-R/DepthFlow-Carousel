# DepthFlow Carousel

**DepthFlow Carousel** is a high-performance, 3D-stacked UI component built with **HTML5, CSS3, and Vanilla JavaScript**. Utilizing custom **cubic-bezier transitions** and **layered Z-indexing**, it creates a premium depth effect that mimics high-end cinematic interfaces.

![Build](https://img.shields.io/badge/build-passing-brightgreen.svg)

## 🌟 Overview

This project delivers a visually striking "stacked" card effect. Unlike traditional sliders, DepthFlow manages multiple background layers to provide a sense of physical perspective. It is lightweight, dependency-free, and highly customizable.

## 🚀 Key Features

- **3D Layered Stacking:** Uses multi-layer offsets (`next-1`, `next-2`) to create a realistic sense of depth.
- **Cinematic Transitions:** Optimized with `cubic-bezier(0.25, 1, 0.5, 1)` for smooth, "heavy" movement.
- **Dynamic Text Animation:** Integrated fade-and-slide logic prevents jumpy text changes during transitions.
- **Bootstrap 5 Integrated:** Uses Bootstrap for structural layout while maintaining a custom aesthetic.
- **Performance Optimized:** No heavy libraries; runs on pure Vanilla JS for maximum speed.

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Styling:** CSS3 (Custom Properties & Flexbox)
- **Framework:** Bootstrap 5 (Grid & Buttons)
- **Logic:** Vanilla JavaScript (ES6+)
